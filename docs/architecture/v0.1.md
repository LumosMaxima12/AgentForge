# AgentForge architecture v0.1

```text
React / Tauri
     │
     │ HTTP
     ▼
FastAPI
     │
 Router
     │
 Service
     │
 Repository
     │
 SQLite (next sprint)
```

## Frontend layers

- `pages`: route-level composition
- `features`: product behavior and domain UI
- `components/ui`: generic reusable primitives
- `lib/api`: HTTP boundary
- `types`: API/domain contracts

## Backend layers

- `api`: transport layer only
- `services`: orchestration and business rules
- `repositories`: data access / aggregation
- `schemas`: API contracts
- `core`: cross-cutting infrastructure

The first Today repository intentionally returns seed data. This keeps UI/API iteration fast and avoids pretending the persistence model is already stable.
