# Today — Design target v0.1

The Today screen is the visual foundation of AgentForge. Its purpose is to answer one question immediately: **what should I learn next?**

## Layout

- Left navigation rail: ~234 px
- Sticky top bar: 70 px
- Main learning column: flexible
- Right insight rail: 336 px on wide desktop, hidden below ~1280 px
- Dark graphite surfaces with a restrained forge-orange accent

## Hierarchy

1. Greeting
2. Next task — strongest visual focus
3. Upcoming tasks
4. Daily study breakdown
5. Calendar, streak, mastery, quick actions

## Interaction rules

- Avoid decorative card overload
- Hover states are subtle (1 px motion at most)
- Orange indicates current/primary action, not generic decoration
- The right rail disappears before the main task area becomes cramped
- Mobile will be designed separately rather than squeezing the desktop UI
